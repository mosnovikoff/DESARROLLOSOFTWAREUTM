Design System - Help Desk

Biblioteca de componentes de interfaz de usuario desarrollada con HTML5 y CSS3. Este UI Kit establece la línea gráfica para el sistema de gestión de incidentes (Help Desk).

Botones

Componentes utilizados para ejecutar acciones principales, secundarias y críticas dentro del sistema Help Desk.

Formularios

Componentes utilizados para la captura de información en el registro y gestión de tickets.
