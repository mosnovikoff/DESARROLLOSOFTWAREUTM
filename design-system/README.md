# Design System - Help Desk

## Descripción

Este proyecto corresponde al desarrollo de una biblioteca de componentes de interfaz de usuario (UI Kit) para un sistema de gestión de incidentes (Help Desk).

El objetivo es establecer una línea gráfica consistente mediante componentes reutilizables desarrollados con HTML5 y CSS3 puro, aplicando variables CSS, selectores avanzados, modelo de cajas y buenas prácticas de diseño.

---

## Tecnologías utilizadas

- HTML5
- CSS3

---

## Componentes desarrollados

- Botones
  - Primario
  - Secundario
  - Peligro

- Formularios
  - Campo de texto (Input)
  - Lista desplegable (Select)

- Tarjetas (Cards)

- Badges
  - Prioridad Alta
  - Prioridad Media
  - Prioridad Baja

---

## Características

- Variables CSS para colores y espaciado.
- Diseño responsive mediante Media Queries.
- Código organizado y comentado.
- Componentes reutilizables.
- Diseño basado en un Design System.
